# Portfólio Acadêmico — [Seu nome]

Site pessoal para apresentar minha trajetória acadêmica, projetos, habilidades e trabalhos desenvolvidos durante a formação em Informática.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- [Animate.css](https://animate.style/) (animações, via CDN)
- [Lucide Icons](https://lucide.dev/) (ícones, via CDN)
- Git e GitHub Pages

## Estrutura

```
portfolio/
├── index.html          # Estrutura das seções
├── css/
│   ├── style.css       # Variáveis, tipografia, layout, header, hero e footer
│   ├── components.css  # Botões, tags, cards, linha do tempo, contato
│   └── responsive.css  # Media queries e movimento reduzido
├── js/
│   ├── script.js       # Menu mobile, navegação ativa, ano, inicialização
│   ├── animations.js   # Animações de entrada (Intersection Observer)
│   └── projects.js     # Dados de projetos, formação e habilidades + geração dos cards
├── assets/
│   ├── images/         # Screenshots e fotos
│   └── icons/          # Ícones próprios (opcional)
└── README.md
```

## Funcionalidades

- Apresentação da trajetória acadêmica
- Exibição de projetos e atividades desenvolvidas
- Seção de habilidades e tecnologias
- Informações de contato
- Layout responsivo para diferentes dispositivos
- Animações e ícones para complementar a interface
